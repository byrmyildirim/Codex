# SOAP CRM Scaffold

This repository provides a minimal starting point for a SOAP-based CRM that interacts with Ticimax WSDL services.

- `src/php/soap_client.php` demonstrates connecting to the Product service using PHP's `SoapClient`.
- `src/java/UrunServiceClient.java` outlines a Java client built with JAX-WS.

Both examples are basic and intended as a foundation for further development.
